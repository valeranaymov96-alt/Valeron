# Valeron

Небольшой учебный проект на Python 3. Скрипт выводит приветствие `World!!!`.

## Запуск

Из папки проекта выполните:

```bash
python tes.py
```

Дополнительные библиотеки не нужны. При импорте `tes` сообщение не выводится;
для вывода можно вызвать функцию `tes.p()`.

## Тесты

Запустите из папки проекта:

```bash
python -B -m unittest discover -v
```

Тесты используют стандартную библиотеку Python: устанавливать зависимости не нужно.
Проверяются вывод при запуске скрипта, отсутствие вывода при импорте
и повторные вызовы функции `p()`. Каждый сценарий запускается в отдельном
процессе Python, чтобы предыдущие импорты не влияли на результат.
