# Valeron

Небольшой учебный проект на Python 3. Скрипт выводит приветствие `World!!!`.

## Запуск

Из папки проекта выполните:

```bash
python tes.py
```

Дополнительные библиотеки не нужны. При импорте `tes` сообщение не выводится;
для вывода можно вызвать функцию `tes.p()`.

## Задание для друга: тестирование интерфейса с Selenium

**Цель:** научиться писать автоматические браузерные тесты на Python с Selenium
WebDriver. Сейчас проект содержит только консольный скрипт, поэтому в рамках
задания сначала нужно добавить небольшую локальную страницу для тестирования.

### 1. Подготовь страницу

Создай `web/index.html` с заголовком «Приветствие», полем имени, кнопкой
«Поздороваться», областью результата и кнопкой «Сбросить».
Реализуй следующее поведение:

- До отправки формы область результата пустая.
- Для имени `Валера` кнопка «Поздороваться» выводит `Привет, Валера!`.
- Пробелы по краям имени удаляются: `  Анна  ` даёт `Привет, Анна!`.
- Пустое имя или строка из пробелов выводят `Введите имя`.
- Повторная отправка заменяет предыдущий результат.
- Кнопка «Сбросить» очищает поле и результат.

Добавь элементам устойчивые уникальные `id`, чтобы тесты могли находить их.
Страница должна работать локально без внешних сервисов и авторизации.
Существующий `tes.py` менять для этого задания не требуется.

### 2. Напиши браузерные тесты

Используй Python, Selenium WebDriver, Chrome и стандартный `unittest`.
Сохрани тесты в `selenium_tests/test_greeting_ui.py`.
Проверяй поведение через действия пользователя: ввод текста и нажатия кнопок.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Открыть страницу | Заголовок и элементы формы видны, результат пустой |
| Ввести `Валера` и отправить | `Привет, Валера!` |
| Ввести `  Анна  ` и отправить | `Привет, Анна!` |
| Отправить пустое поле | `Введите имя` |
| Отправить только пробелы | `Введите имя` |
| После приветствия отправить другое имя | Показано только новое приветствие |
| После ошибки ввести корректное имя | Ошибка заменена приветствием |
| Нажать «Сбросить» после приветствия | Поле и результат пустые |

Каждый тест должен быть независимым. Закрывай браузер даже при падении теста.
Для ожидания состояния элементов используй явные ожидания вместо `time.sleep()`;
не смешивай их с неявными ожиданиями.
Справочник: [ожидания в Selenium](https://www.selenium.dev/documentation/webdriver/waits/).

### 3. Подготовь воспроизводимый запуск

Добавь Selenium в `requirements-selenium.txt` и укажи проверенную версию.
Документируй установку зависимостей и требования к Chrome/WebDriver.
Для локальной страницы можно запустить из корня проекта:

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory web
```

Пока сервер работает, страница доступна по адресу `http://127.0.0.1:8000/`.
В другом терминале запускай браузерные тесты отдельно от существующих:

```bash
python -B -m unittest discover -s selenium_tests -p "test_*.py" -v
```

Эти команды предназначены для файлов, которые нужно создать в рамках задания.

### Критерии готовности

- Все восемь сценариев покрыты автоматическими проверками и проходят.
- Если намеренно изменить текст приветствия, соответствующий тест падает;
  после проверки правильное поведение восстановлено.
- В README описан запуск с нуля, указаны проверенные версии Python и браузера.
- Приложен краткий отчёт: команда запуска, число успешных тестов и найденные ошибки.

**Дополнительно:** добавь запуск Chrome в headless-режиме и сохранение скриншота
при падении теста.
